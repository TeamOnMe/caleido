# Промпт для OpenCode на VPS (работаешь прямо по ssh)

Запусти в папке проекта: `cd /root/projects/caleido && oc "<промпт ниже>"`
(или интерактивно: `opencode` в этой папке — он сам прочитает AGENTS.md).

---

Ты — агент разработки проекта «Калейд» (PWA-счётчик калорий, без сборки: index.html + app.js).

Первым делом прочитай полностью файлы AGENTS.md, STATUS.md и PLAN.md в текущей папке —
это твои правила, статус и план. Работай строго по ним:

1. Проверь лок в разделе «Текущая работа» файла STATUS.md. Если занято менее 2 часов назад кем-то другим — остановись и сообщи мне.
2. Запиши свой лок (кто: OpenCode-VPS, время), потом работай.
3. Бери ближайшую незакрытую задачу из PLAN.md (стадии идут по порядку). Не выдумывай новые фичи.
4. После изменений обязательно: `node tests/test_app.js` (все тесты зелёные; новая фича = новый тест).
5. Деплоить на прод (/var/www/site/caleido) запрещено без явного письменного «да» от Тимофея.
6. Закончил: обнови STATUS.md (что сделано/осталось, сними лок), допиши строку в JOURNAL.md, сделай git commit с понятным сообщением на русском.

Отчёт в конце: что сделал, какие тесты гонял, что осталось, ссылки на изменённые файлы. Пиши просто, по-русски, без жаргона — заказчик не технарь.
