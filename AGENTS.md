# AGENTS.md — правила работы над проектом «Калейд»

Этот файл читают все агенты (Hermes, OpenCode на VPS, OpenCode на компьютере).
Он единственный источник правил. Не додумывай свои — если чего-то нет, спроси
у Тимофея (он принимает все решения).

## Где проект
- Код и доки: `/root/projects/caleido/` (на VPS).
- Прод-сайт: `https://diantus.mooo.com/caleido/` — это копия из `/var/www/site/caleido/`.
- Архивы и бэкапы: `artifacts/`.

## Обязательный порядок работы
1. **Сначала прочитай** `STATUS.md` и `PLAN.md` — там текущий статус, стадии и
   решения Тимофея. Не работай по памяти.
2. **Возьми лок**: в `STATUS.md`, раздел «Текущая работа», запиши: кто работаешь
   и время. Если там уже кто-то записан менее 2 часов назад — НЕ трогай проект,
   дождись или спроси Тимофея.
3. **Работай по плану**: бери задачи из `PLAN.md` в порядке стадий. Если задача
   не из плана — сначала согласуй с Тимофеем и добавь в план.
4. **Проверяй**: запусти `node tests/test_app.js` — все тесты должны быть зелёные.
   Новая фича = новые тесты.
5. **После работы обязательно**:
   - обнови `STATUS.md` (что сделано, что осталось, время, сними лок);
   - добавь строку в `JOURNAL.md` (дата, кто, что сделал, ссылка на стадию плана);
   - закоммить изменения в git: `git add -A && git commit -m "коротко: что сделано"`.

## Жёсткие правила
- **Деплой на прод** (`/var/www/site/caleido/`) — ТОЛЬКО после явного «да» от
  Тимофея в чате. Сначала показать, что меняется, потом ждать подтверждения.
- **Не удаляй** файлы в `artifacts/` и не перезаписывай `JOURNAL.md` — только дописывай.
- **Не ломай чужую работу**: если в git видны свежие незакоммиченные чужие правки — не трогай их.
- **localStorage — данные пользователя телефона**: код не должен их терять. При
  изменении структуры данных позаботься о совместимости со старыми сохранениями.

## Стиль (важно — заказчик не технарь)
- Отчёты и интерфейс — простой русский язык, без жаргона. Кнопки крупные,
  подсказки «что делать».
- Учебные материалы для Тимофея — в Word (.docx).

## Технические примечания (проверено на практике)
- Веб-приложение без сборки: `index.html` + `app.js` + `manifest.webmanifest` + `icon.svg`.
  Никаких npm-зависимостей. Тесты — plain `.js` с моками localStorage/document, запуск `node tests/test_app.js`.
- Скрипт в index.html грузить с `defer`.
- Хелпер `$` в app.js принимает и `$("id")`, и `$("#id")`.
- Фиксированный footer перекрывает низ — в CSS нужен `padding-bottom: 110px + safe-area`.
- Прод-деплой: копировать `index.html app.js manifest.webmanifest icon.svg` в `/var/www/site/caleido/`.
- Git: коммитить после каждой законченной задачи (история = страховка между агентами).

## Схема: три агента, одна папка
| Агент | Где | Роль |
|---|---|---|
| Hermes | VPS, чат Тимофея | оркестрация, деплой, отчёты, сложные задачи |
| OpenCode (VPS) | VPS, ssh, эта же папка | кодинг и тесты, много запросов (400/сут) |
| OpenCode (компьютер) | компьютер Тимофея, смонтированная папка | кодинг и тесты |

Агенты работают по очереди, друг друга не топчут (лок + git + журнал решений).
Решения принимает Тимофей. Все агенты читают этот файл — поэтому дружат.
