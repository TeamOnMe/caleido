# Калейд — чек-лист доработки (обновляется по ходу)

## Решения Тимофея (02.11.2026)
- Аллергии/нелюбимое: генератор полностью исключает такие продукты; своя вкладка «Настроить» в нижнем меню
- Замена блюда: точечно по дням (🔁 у каждого приёма, меняет только этот приём этого дня) — код уже есть, протестировать+задеплоить
- КБЖУ на порцию: две строки в карточке — «на 1 порцию» крупно + «всё блюдо» мельче; число порций проставляет разработчик по смыслу
- Магазин: цены примерные + ссылка на поиск товара; по умолчанию Пятёрочка, переключатель Пятёрочка/Магнит в списке покупок; один общий список
- Ручной ввод: кнопка «+ Я поел» у каждого приёма; поиск по справочнику с автоподстановкой КБЖУ; нет в базе — ввести вручную и сохранить в «свои продукты»; день = план + дописанное
- Расширить справочник ~40 продуктами (фрукты, сладости, напитки, снеки) с КБЖУ+ценами
- Всё новое хранится в localStorage и попадает в архив/восстановление
