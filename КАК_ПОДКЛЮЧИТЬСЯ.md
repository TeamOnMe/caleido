# Как подключиться к папке проекта с компьютера (для OpenCode на ПК)

Папка проекта лежит на VPS: `/root/projects/caleido`.
Чтобы OpenCode на компьютере работал в этой же папке, её нужно «подключить» по SSH.

## Windows
1. Поставь WinFsp + SSHFS-Win: https://github.com/winfsp/sshfs-win/releases (установщик по умолчанию).
2. В «Проводнике» → «Подключить сетевой диск», буква диска например `Z:`:
   путь: `\\sshfs\root@<IP или diantus.mooo.com>\root\projects\caleido`
   (пароль — от сервера; если настроен ssh-ключ, спроси у Hermes помощь).
3. Открой OpenCode в папке `Z:\` — он прочитает AGENTS.md сам.

## macOS
1. `brew install macfuse sshfs` (перезагрузка может понадобиться один раз).
2. `mkdir -p ~/caleido && sshfs root@<сервер>:/root/projects/caleido ~/caleido`
3. Открыть OpenCode в `~/caleido`.

## Linux
`sudo apt install sshfs && mkdir -p ~/caleido && sshfs root@<сервер>:/root/projects/caleido ~/caleido`

## Важно для всех
- Не работай из двух агентов одновременно — смотри лок в STATUS.md (правила в AGENTS.md).
- Если связь с сервером пропала — закрой редактор, переподключи диск, перечитай STATUS.md.
- Все изменения уже защищены git-коммитами на сервере; локально ничего критичного не хранится.
