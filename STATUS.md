# Статус проекта «Калейд» — PWA-счётчик калорий и рацион на неделю
Обновлено: 25.10.2026 (вечер)

## Что это
Веб-приложение (PWA): расчёт нормы КБЖУ по параметрам (пол, возраст, рост, вес,
активность, цель), генератор меню на неделю (завтрак/обед/полдник/ужин) из 28
домашних рецептов, список покупок, дневник приготовленного. Данные хранятся в
localStorage телефона, аккаунт не нужен.

## Где лежит
- Код:            /root/calorie-app/  (index.html, app.js, sw.js, manifest)
- Прод-версия:   https://diantus.mooo.com/caleido/  (копия /var/www/site/caleido/)
- Архив для передачи: /root/caleido-app.zip  (устарел — пересобрать после доработок)
- Тесты были в scratch (test_app.js/test_swap.js) — очищены сборщиком; при
  необходимости восстановить из этой папки или переписать.

## Готово и проверено
- Полный цикл UI протестирован в браузере (расчёт, дни, рецепты, покупки,
  дневник, перезагрузка с восстановлением). Мобильная вёрстка 390px починена
  (padding-bottom 110px+safe-area под фикс. таб-бар; $ принимает '#id' и 'id';
  defer на скрипте).
- В КОДЕ ЕСТЬ новая фича: замена одного блюда 🔁 («Заменить» у каждого приёма,
  swapMeal/buildMeal — меняет только завтрак/обед/ужин, калорийность приёма
  держит). Синтаксис OK. НЕ задеплоено, НЕ тестировано в браузере.

## Незаконченные задачи (в порядке приоритета)
1. КБЖУ на 1 ПОРЦИЮ (просьба пользователя от 24.10, НЕ сделана): сейчас
   карточка блюда показывает калорийность всего блюда/рецепта целиком. Нужно:
   - поле «порций в блюде» (default 1–4, задаётся в рецептах RECIPES),
   - отображение КБЖУ на порцию + общий выход,
   - дневник и список покупок остаются по целым блюдам (покупки — граммы
     ингредиентов, не менять).
2. Прогнать юнит-тесты замены блюда (swap: другие приёмы не меняются, ккал
   приёма держится ±25%, повторные свопы дают разные блюда).
3. Задеплоить в /var/www/site/caleido/ (сейчас прода ОТСТАЛ от локального кода —
   diff app.js показывает различия) + проверить live-URL в мобильном viewport.
4. Пересобрать /root/caleido-app.zip (python3 -m zipfile -c caleido-app.zip calorie-app).

## Pitfalls (проверено на практике)
- Фикс. footer перекрывает последние кнопки без padding-bottom 110px + safe-area.
- Помощник $ в app.js чистит '#' — вызовы вида $("sexSeg") и $("#sexSeg") оба валидны.
- Скрипт должен грузиться с defer.
- zip в системе нет — собирать через `python3 -m zipfile`.
- pkill по имени процесса в терминале VPS может убить собственный shell-вызов
  (SIGTERM); завершать процессы аккуратнее.
- node v26 на сервере есть — тесты писать как plain .js с моками localStorage/document.
